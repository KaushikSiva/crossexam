# CrossExam landing page

Visual thesis: neutral black and white, editorial typography, and a studio-lit silver 3D CrossExam gate. No green tint or colored status fills. State is communicated with words, marks, borders, and line patterns.

Content: product and real-time 3D illustration; a concrete two-request counterexample; measured suite evolution; an OpenUI evidence brief; reproducible source and narrated film.

Three.js renders original extruded geometry, physical metal materials, and input paths. Pointer movement reveals depth. Motion pauses offscreen; reduced-motion mode removes drift and parallax. A vector fallback preserves the composition when WebGL is unavailable.

All measurements come from the bundled report. The 3D scene is explicitly an illustration; it never claims a new model call.
