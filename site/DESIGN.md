# CrossExam landing page

Visual thesis: an oversized editorial title on dark green-black, interrupted by a precise animated fracture through a passing test signal; the page unfolds into warm-paper evidence.

Content plan: product name and one arresting live vector composition; a concrete two-request counterexample; measured suite evolution; an interactive OpenUI evidence brief; reproducible source and the one-minute film.

Interaction thesis: a cursor-reactive lattice bends around the X motif; scrolling draws a measured learning curve and reveals the rejected proposal; an OpenUI renderer builds selectable evidence briefs from saved run data. Reduced-motion mode removes parallax and drawing animations.

All numbers come from the bundled report JSON. Motion must never imply an API request or live execution when it is presenting recorded evidence.
