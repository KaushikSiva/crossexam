# Evidence workspace design

Visual thesis: a quiet editorial laboratory, with warm paper, dark ink, and acid yellow indicating the active investigation.

Content plan: current run and measured outcomes; an executable counterexample; the version-by-version learning curve; final audit and downloadable provenance.

Interaction thesis: selected evidence reveals its request trace and source diff; learning curves animate once on entry; live execution updates a compact event rail. A saved run is always labeled recorded evidence.

The screenshots and video must show actual report data. No invented partner results, fabricated score animations, or unlabeled staged failures.
